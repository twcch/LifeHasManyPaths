## 📖 專案簡介

**《人生不只一條路》（LifeHasManyPaths）** 是一款以台灣現代社會為背景的**免費單機文字冒險與人生模擬遊戲**。

玩家將投胎成一個台灣人，從 0 歲隨機家世際遇開始，7 歲起逐年經歷升學備考、兵役體檢、求職升遷、投資理財、買房成家、副業接案、身心調適到晚年退休，一路走向生命的終點結算。

遊戲的核心理念為：**「同一個出生起點，也能因為讀書、工作、關係、金錢和臨時抉擇，走出截然不同的人生路線。每局都可以重新選擇，沒有唯一正確的人生。」**

## ✨ 遊戲核心特色

### 🎲 1. 種子隨機開局與命運光環
- **全台 22 縣市出生登記**：北北基桃、中彰投、雲嘉南、高屏、宜花東與金馬澎，各自擁有專屬在地風情與資質加成。
- **真實隨機家境**：偏鄉清寒 (就學貸款開局)、普通中產 (踏實打拚)、有礦豪門 (自帶創業金援與跌倒保護傘)。
- **天生六維數值**：顏值、智力、體質、快樂 (0–100)，以及影響投機與際遇的隱藏屬性 (運氣、信仰)。

### 🎯 2. 骰子特訓與潛力天花板
- 借鏡養成遊戲核心機制，**8 大專長**皆有天生上限 (由出生種子碼決定)。
- 8–50 歲每 3 年固定獲得 2 顆特訓骰，達成人生章節目標或特殊成就亦會額外獎勵特訓骰，由你策略分配訓練重點，將潛力化為實質實力。

### 🧭 3. 人生章節挑戰系統
- 告別盲目狂按下一年！童年、青年、中年到老年，系統會根據當前狀態與人生志向，從 13 種目標抽出限時章節挑戰 (進修、成家、存錢、買房、副業、旅行等)，達成即賞特訓骰。

### 🗂️ 4. 六大主動生活面向
- 每年除隨機事件外，享有一次主動行動機會:
  - **成長**: 專長補習、證照考取、技能養成
  - **身心**: 心理諮商、健康檢查、休養放鬆
  - **關係**: 聯誼交友、陪伴家人、社交經營
  - **理財**: 兼職副業、股票投機、合約買賣、資產配置
  - **冒險**: 出國壯遊、簽賭博弈、挑戰極限
  - **生活**: 領養寵物、犒賞自己、享受當下

### 💼 5. 多元台灣在地職涯與荒謬時事梗
- **數十條職業進階階梯**: 竹科工程師、醫師律師、公務員鐵飯碗、傳統農工餐飲、遊戲實況主、百萬網紅、職業啦啦隊、職棒球星、政壇風雲到角頭黑道。
- **豐富在地時事事件包**: 柬埔寨高薪陷阱生還、地下錢莊討債跑路、全額貸買車、半夜牛肉麵、兵役教召與海外流亡、高齡人瑞重陽敬老祝壽等上百個精彩事件。

### 📜 6. 跨年齡深度故事線
- **「爸爸鋪好的路：從承諾到夢醒」**：出生抽中保險業務家庭專屬伏筆，面對承諾與夢醒、課業落後、課金衝突與國營備考自立。

### 🏆 7. 115 項成就圖鑑與長圖分享
- 收錄豐富社會歷程與隱藏傳奇結局，即時儲存於瀏覽器 `localStorage`。
- 結算畫面自動繪製「快樂指數」與「總資產成長」雙走勢曲線，給出 D～SSS 終生評級，並支援一鍵生成精美長圖分享。

### ⚡ 8. 零依賴 · 純前端單機
- 免下載、免註冊、無伺服器後端負擔，任何手持裝置與電腦瀏覽器點開即玩。
- 專為手機單手操作優化的響應式直式排版，電腦亦完整支援鍵盤快捷鍵 (`Space` 繼續人生、`A` 主動行動、`R` 重新投胎、`Esc` 關閉圖鑑)。

## 🚀 本地執行與開發

本專案為**純前端靜態網頁**，無須安裝 Node.js 或建置編譯工具：

1. **直接開啟**：
   將專案下載至電腦後，直接使用瀏覽器雙擊開啟 `index.html` 即可暢玩。

2. **使用本機靜態伺服器（推薦）**：
   ```bash
   # 使用 Python 內建伺服器
   python3 -m http.server 8080

   # 或使用 Node.js npx serve
   npx serve .
   ```
   瀏覽器打開 `http://localhost:8080` 即可進行測試與開發。
